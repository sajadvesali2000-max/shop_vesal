# webapp/

این پوشه شامل نسخهٔ مستقلِ وب‌اپ است که می‌توانید آن را در زیر مسیر `docs/webapp/` قرار دهید تا با GitHub Pages یا هر میزبان استاتیک دیگری قابل دسترسی باشد.

فایل‌ها:
- index.html — صفحهٔ اصلی وب‌اپ (client-side). وقتی به لینک `.../webapp/` بروید این صفحه لود می‌شود و تمام کدهای JS/CSS اجرا می‌شوند.
- api/send-order.js — نمونهٔ handler سروری (serverless) که باید در محیطی مثل Vercel یا Netlify مستقر شود. این فایل در GitHub Pages قابل اجرا نیست؛ فقط نمونهٔ مرجع است.

نکات مهم برای ارسال سفارش به تلگرام:
1. برای امنیت، توکن بات تلگرام را در متغیرهای محیطی سرویس سرورلس خود قرار دهید، هرگز آن را در کد عمومی یا repo قرار ندهید.
2. مقدار `ORDER_URL` در `index.html` را به URL تابع serverless خود (مثلاً `https://your-app.vercel.app/api/send-order`) تنظیم کنید. اگر تابع را روی همان هاست پیاده می‌کنید مسیر `/api/send-order` مناسب است.
3. در محیط سرورلس، متغیرهای زیر را تنظیم کنید:
   - TELEGRAM_BOT_TOKEN = <توکن بات>
   - TELEGRAM_CHAT_ID = <chat id مدیر>
4. بعد از تست، حتماً توکن را در BotFather ریست کنید تا توکن افشا شده غیرفعال شود.

اگر خواستید من می‌توانم راهنمای مرحله‌به‌مرحله برای deploy به Vercel یا Netlify بنویسم.
